Accounts

A new account and a reset both get a one-time password, shown once here; the user is asked to choose their own at next sign-in. Roles: admin manages accounts and the oligo export; user and student are the same for now (student limits wait for the approval queue). The last admin cannot be demoted or removed. Password set is when the person last chose their own password (recorded since 2026-10-29; "—" means not since then). Last active is the last request they made (recorded since 2026-10-29, to the minute). Click a column to sort.

Basic view

What people see in the map bank when they choose Basic (top right of every page). Unticked tools are only in Advanced. Browsers that used the site before 29 October start in Advanced; new ones start in Basic. Everyone can switch at any time.

Oligo collection

Upload the oligo database export (the whole export or only the newest rows). Rows are matched on Oligo id: new IDs are added, an ID whose sequence changed is updated, and nothing is removed. The previous version is kept as one step of undo on the server.
